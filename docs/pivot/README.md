# The pivot

On 30 September 2026 the project stopped its two-track, Mac-lane workflow and re-based its methodology.
The trigger was a finding. Every published record read its inputs 4–5 business days before the day it
forecast. The benchmark was handicapped in the same way, so the published comparisons were between two
stale forecasts.

| File | What it is |
|---|---|
| [`next-session.md`](next-session.md) | **Start here.** State with check commands, reading order, tasks, pending decisions |
| [`lag-assessment.md`](lag-assessment.md) | The finding: root cause, measured impact, how far it reaches, the fix, alternatives rejected |
| [`plan.md`](plan.md) | The redesign: methodology, data, testing, workflow, bottlenecks, sequence, task briefs |
| [`history.md`](history.md) | The first three weeks, consolidated: what stands, what must be re-measured, lessons kept |
| [`literature.md`](literature.md) | Similar work and borrowable methods, with links |

The rulings are in `docs/decisions/`: `information-set.md`, `workflow.md` and `publish-rule.md`. The scouting
scripts behind the numbers are in `notebooks/scouting/`.
