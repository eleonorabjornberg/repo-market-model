# The pivot

**This folder is the only place the pivot is documented.** Anything elsewhere links here.

The project's current plan and status. On 30 September 2026 it re-based its methodology. Every published record
had read its inputs 4–5 business days before the day it forecast, and the benchmark was handicapped the same way, so
the records are being re-scored under an as-of information rule.

| File | What it is |
|---|---|
| [`next-session.md`](next-session.md) | **Start here.** State with check commands, reading order, tasks, pending decisions |
| [`lag-assessment.md`](lag-assessment.md) | The finding: root cause, measured impact, how far it reaches, the fix, alternatives rejected |
| [`plan.md`](plan.md) | Methodology, data, testing, workflow and the sequence |
| [`directives/`](directives) | One brief per step of the sequence; each becomes a GitHub issue |
| [`literature.md`](literature.md) | Similar work and borrowable methods, with links |
| [`scouting/`](scouting) | The scripts behind the assessment's numbers, with their recorded output |

The rulings are in `docs/decisions/`: `information-set.md`, `workflow.md` and `publish-rule.md`. Superseded documents
are in `docs/archive/`, which is not binding.
