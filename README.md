Every day, banks, dealers and money-market funds lend each other trillions of dollars overnight against U.S.
Treasury securities: the repo market. On most days the rate on that cash, SOFR, sits at or just below the rate the
Federal Reserve pays banks on their reserves, IORB. On some days — tax dates, large Treasury settlements, month- and
quarter-ends, above all when reserves are getting scarce — spare cash runs short and SOFR jumps above it, as it did in
September 2019. This project asks one question of public data only, using only what was public at 4 pm the day before:
**what is the chance that tomorrow SOFR is more than 5 basis points above IORB?** ([The event is defined here.](docs/decisions/pressure-probability.md)) It is an academic and portfolio
project, built to show how such a forecast can be made and tested without borrowing from the future.

**Live site:** [the explorer](https://eleonorabjornberg.github.io/repo-market-model/): the data, the market mechanics and the information rule on one page (source: [`site/`](site), generated by [`scripts/emit_visual.py`](scripts/emit_visual.py)); the result of the final test, near-blind and run once, has [its own section](https://eleonorabjornberg.github.io/repo-market-model/#final-test).

## Quick start

Requirements: Python 3.11, declared once in `pyproject.toml` and checked against the interpreter that runs the
suite; 3.12 moves the published figures in their last digits and is outside it. Everything a published result depends
on is the Python standard library, except the gradient-boosted comparison, which needs `pip install '.[ml]'`.

```bash
git clone https://github.com/eleonorabjornberg/repo-market-model.git
cd repo-market-model

python3 examples/walkthrough.py        # the whole pipeline on the sample data: no install, no network

PYTHONDONTWRITEBYTECODE=1 PYTHONPATH=src \
  python3 -B -m unittest discover -s tests

PYTHONPATH=src python3 -m repo_model.cli audit data/sample/daily_market.csv
PYTHONPATH=src python3 -m repo_model.cli backtest data/sample/daily_market.csv \
  --registry metadata/sources.json \
  --feature spread_bps \
  --decision-time 16:00 \
  --model persistence \
  --report /tmp/persistence_sample.json
```

The sample file is synthetic and exists only to make the workflow executable.
For data acquisition and exact reproducibility boundaries, see
[`REPRODUCIBILITY.md`](REPRODUCIBILITY.md).

The machine-learning settings, and which commands take them, are under [Command options](PROJECT_GUIDE.md#command-options).

**Use limitation.** A research forecast of the SOFR − IORB spread. It is not a stress-warning system and not a basis for VaR, limits, liquidity or capital, or desk sizing. Its central quantiles are not yet calibrated, its tail coverage is weaker on quarter-ends and turns, and it has little history in the current scarce-reserve regime. It needs revalidation after a material policy or regime change.
